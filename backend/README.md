# CodeForge - Backend Service

This directory is designated for the CodeForge backend services.

## Planned Architecture
According to the system architecture specification:
- **Core Engine**: Java Spring Boot (REST Controllers, Business Services, JWT Security, Integration Dispatcher)
- **Database**: Microsoft SQL Server (Users, Exercises, Submissions)
- **Sandbox Execution**: Judge0 API Integration
- **Notification**: Email Notification Service

Backend implementation will be integrated here in the next phase.
