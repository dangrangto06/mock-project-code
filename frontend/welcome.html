Problem #104 — Pair Sum (Two Sum) 
# Given nums = [2, 7, 11, 15] and target = 9
def pair_sum(nums: list[int], target: int) -> list[int]:
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []

Frequently Asked Questions

Everything you need to know about using CodeForge as a guest or member.

Can I practice on CodeForge without creating an account? ↓

Yes! Guests can browse the entire catalog of 100 problems and run code freely in the Web IDE. Creating a free account allows you to save progress, earn daily streaks, track solved problems, and author your own challenges.

What programming languages are supported? ↓

CodeForge supports Python 3, JavaScript (Node.js), Java (OpenJDK), and C++ (GCC). Each challenge includes starter code templates and type definitions tailored to your chosen language.

Do I need to install any software or local compilers? ↓

Zero installation required. Code execution runs securely in an isolated sandbox. All you need is a modern web browser.

How does the automated grading runner work? ↓

When you click "Run Code", the platform executes your code against public sample cases with stdout logging. When you click "Submit", it evaluates against comprehensive hidden edge-case suites, verifying constraints, time limits, and memory usage.
